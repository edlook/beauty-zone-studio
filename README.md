# Beauty Zone Studio — Yana Finoshkina (статическая копия)

Сайт в виде обычных HTML-файлов: сборка не нужна, достаточно открыть `index.html`.

## Страницы
- `index.html` — Startseite
- `permanent-make-up.html` — Permanent Make-up (новая, по материалам Instagram)
- `wimpern.html` — Wimpern
- `wimpernverlangerung-schulung.html` — Schulung
- `impressum.html` — Kontakt & Impressum

## Файлы
- `assets/logo.svg` — логотип (монограмма BZ + «Beauty Zone», текст переведён в контуры)
- `assets/logo-mark.svg` — только монограмма (аватар, шапка соцсетей)
- `favicon.svg` — иконка вкладки
- `assets/index-*.css` — оригинальные стили сайта (шрифты DM Sans и Lora из Google Fonts)
- `assets/custom.css` — дополнения: логотип, карточки, FAQ, цитата
- `assets/img/` — фото Unsplash (Symbolfotos)

Переключение слайдов в hero на главной — небольшой скрипт в конце `index.html`.
Ссылки относительные: папку можно положить на любой хостинг или в подпапку.
